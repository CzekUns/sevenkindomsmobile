# Seven Kingdoms: Ancient Adversaries — nel browser

Build in WebAssembly della versione 2.15.7 del progetto 7kfans (codice e dati di gioco GPL-2.0, Enlight Software; «Seven Kingdoms» è un marchio di Enlight). La musica di Bjorn Lynne ed Enlight (1997) è ridistribuita integra con la sua nota, vedi `COPYING-Music.txt`. Licenze complete in `COPYING.txt`.

Sorgenti del gioco: https://sourceforge.net/projects/skfans/ — le quattro modifiche minime ai sorgenti e gli script di compilazione si forniscono su richiesta, come previsto dalla GPL.

Comandi: sul PC il mouse come nell'originale (sinistro seleziona, destro ordina); sul telefono, tenuto di lato, tocco = sinistro e pressione lunga = destro. I salvataggi restano nel browser.
